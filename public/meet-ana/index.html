PRIVACY IS NOT A FOOTNOTE

Ana should help you communicate.
Not quietly collect your typing.

The keyboard is built so ordinary typing and local correction stay separate from Ana’s cloud AI features. When cloud AI is needed, the user chooses the feature or explicitly enables it.

Ana is still in private testing. Privacy controls reduce exposure, but users should still avoid sending information to any AI service that they are not comfortable processing in the cloud.

⌨

Normal typing stays local

Basic key input, local suggestions, autocorrection, learned words and glide decoding do not need a cloud request. Smart paragraph correction is a separate opt-in feature.

◇

Sensitive fields are treated differently

Password and OTP-style fields disable Ana AI behaviour. Clipboard and voice features are also kept out of private input contexts.

◎

Privacy Shield before AI

When enabled, Ana can mask recognised sensitive values such as names, emails, amounts and banking-style identifiers before sending text for AI processing, then restore the protected values afterwards.

◐

Incognito really changes behaviour

Incognito mode pauses Ana AI, learning and clipboard history instead of merely changing the colour of the keyboard.

▣

Per-app AI control

Ana can keep AI actions disabled for apps where you do not want them, while the keyboard itself remains usable.

✓

Reply does not scrape your screen

Ana replies only to text you deliberately select, copy or place in the editor. It does not silently read surrounding WhatsApp, Gmail or other app content.
