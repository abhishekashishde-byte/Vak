Ana Platform

Put Ana inside your software.

Translation is useful. Communication is bigger. Ana Platform gives products a server API for meaning-first translation, speech transcription and the realtime foundation behind Talk for Me.

Private betaBuilt, but gated by API keys.

Ana Platform endpoints are deployed with the product, but external access stays disabled until a server-side Ana Platform key is configured. Partner keys should never be embedded in a public browser or mobile bundle.

Server first

Your backend calls Ana. Ana’s credentials and your partner key stay off the end user’s device.

Meaning before words

Translation keeps intent, tone, names, reference numbers, dates and amounts in view rather than treating every sentence as isolated text.

Decisions stay with the owner

Talk for Me exposes explicit decision and verification tools instead of letting an autonomous voice agent quietly make consequential choices.

API v1

Three building blocks.

Use one independently or combine them. A meeting product may only need transcription + translation; a service app may use Talk for Me as a voice-agent layer.

POST
/api/v1/translate

Translate

Meaning-first text translation for product interfaces, messages, documents and backend workflows.

  • Auto-detect or source hint
  • Target language
  • Optional context
POST
/api/v1/transcribe

Transcribe

Convert short base64 audio segments to text while preserving multilingual speech and code-switching.

  • Up to 8 MB per segment
  • Optional language hint
  • No translation forced
POST
/api/v1/talk-session

Talk for Me

Create a short-lived realtime session configured around an owner goal and Ana’s critical-decision tools.

  • Owner goal + constraints
  • Two languages
  • Owner escalation contract
Quick start

Call Ana from your backend.

All v1 endpoints accept Authorization: Bearer YOUR_ANA_PLATFORM_KEY. The code below is intentionally server-side.

const response = await fetch('https://vak-gray.vercel.app/api/v1/translate', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.ANA_PLATFORM_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    text: 'Könnten wir den Termin auf nächste Woche verschieben?',
    target: 'English',
    context: 'Scheduling a service appointment'
  })
})

const { translation } = await response.json()
const session = await fetch('https://vak-gray.vercel.app/api/v1/talk-session', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.ANA_PLATFORM_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    goal: 'Ask whether Friday after 15:00 is available. Do not accept another time without asking me.',
    ownerLanguage: 'English',
    otherLanguage: 'German'
  })
}).then(r => r.json())

// session.client_secret is short-lived. Use it to establish the
// Realtime connection. Your integration handles Ana's tool calls.

Talk for Me trust contract

A voice agent should not confuse “can speak” with “can decide.”

The realtime session is configured around the owner’s explicit goal. Partner software receives three tool responsibilities so important choices remain visible and verifiable.

record_critical_fact

Track names, dates, prices, quantities, eligibility, commitments and other facts that matter to task completion.

ask_owner

Stop before an unapproved material decision and bring the exact question back into the partner’s UI.

complete_task

Only finish after required facts are confirmed or explicitly unavailable; reject completion if important requirements are still missing.

Private beta access

Keep the platform closed until you choose the partners.

Set a server-side key list in the deployment when you are ready. Until then, external API calls return a private-beta message instead of exposing Ana publicly.
